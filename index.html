A. Autonomy & Execution Independence

Evaluates the degree to which the agent plans, selects tools, and executes multi-step chains without requiring a human operator in the loop. High autonomy increases the probability of goal drift or unexpected tool execution sequences.

B. Data Classification Scope

Measures the highest sensitivity level of data exposed to the model's context window, prompt history, or vector store. Restricted data introduces regulatory compliance triggers (GDPR, HIPAA, PCI-DSS) and higher indirect prompt injection impacts.

C. Action Execution Scope

Evaluates OWASP Excessive Agency risks. Determines whether the agent performs read-only lookups or holds active API write, update, or administrative delete execution permissions against backend systems.

D. Identity & Authentication Context

Assesses privilege delegation. Agents executing via delegated OAuth user contexts maintain existing RBAC controls, while shared or elevated service accounts bypass individual accountability and risk broader privilege abuse.

E. Action Reversibility

Determines the potential impact of agent failure or hallucination. Irreversible actions (e.g., broadcasting emails, executing financial transfers) present immediate blast-radius threats requiring mandatory human-in-the-loop oversight or Tier 3 security review.
